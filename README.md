# 🚗 자동차 정비기능사 실기 마스터 (1안~15안 완벽 대비 모바일 웹앱)

> **"1안부터 15안까지 탈부착 실습 체크리스트 & 실기 기록표(답안지) 인터랙티브 작성 훈련"**
> 
> 한국산업인력공단(Q-Net) 자동차정비기능사 실기 시험 수험생을 위해 안드로이드·아이폰에 100% 최적화된 모바일 퍼스트 실기 대비 웹 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 📱 모바일 퍼스트(Mobile-First) 안드로이드 & 아이폰 완벽 최적화
- **Safe Area Inset 대응**: 아이폰 Dynamic Island 및 하단 홈 바 영역 완벽 처리 (`viewport-fit=cover`).
- **한 손 조작 하단 네비게이션**: 실습 중 엄지손가락으로 쉽게 탭할 수 있는 하단 탭 바 (`[안 선택]`, `[기관]`, `[섀시]`, `[전기]`, `[검사족보]`).
- **화면 켜짐 유지 (Wake Lock API)**: 정비 작업복이나 장갑 착용 중 화면이 꺼지지 않도록 원클릭 토글 지원.

### 2. 📋 1안 ~ 15안 공개문제 과제 종합 매트릭스
- 기관, 섀시, 전기 3대 영역의 **탈거/조립 과제**, **기록표 작성 과제**, **시동 고장 1개소**, **자기진단 센서**, **법정 검사** 일괄 수록.
- 상단 가로 스크롤 탭으로 1~15안 자유 전환 및 실시간 학습 진행률(%) 뱃지 표출.
- **당일 시험 대비 랜덤 1안 추첨 모의고사 모드** 지원.

### 3. 🛠️ 탈거·조립 인터랙티브 실습 체크리스트
- **필요 공구 목록 & 안전 보호구 수칙** 안내.
- **분해 순서 ➔ 🚨[감독위원 대면 확인] ➔ 규정 토크 조립 순서**의 단계별 체크리스트.
- 수험생이 스마트폰으로 실습 단계를 직접 누르며 진도를 체크할 수 있는 직관적인 UI.
- 실기 시험 감점 방지(체결 토크, 오일 도포, 가스켓 방향) 핵심 꿀팁 제공.

### 4. 📝 실기 기록표(답안지) 인터랙티브 훈련장
- 실제 Q-Net 시험 답안지 서식과 100% 동일한 레이아웃 (`[측정항목] | [규정값] | [측정값] | [판정(양호/불량)] | [정비 및 조치할 사항]`).
- **원터치 칩 입력 모드**: 작은 모바일 키보드로 타이핑하기 힘든 학생들을 위해 규정값 및 표준 조치사항 문장 선택 칩 제공.
- **감점 제로 모범 답안 족보**: 다양한 시나리오(높을 때, 낮을 때, 부품 고장, 과거기억 미소거 등)별 정답 및 상세 해설 즉시 토글 확인.
- 브라우저 로컬스토리지 자동 저장으로 작성 답안 유실 방지.

### 5. 📜 법정 검사 규정값 & 계산 공식 족보
- **제동력 산출 공식 실시간 자동 계산기**: 축중, 좌/우 제동력 입력 시 편차(8% 이하) 및 합(50% 이상) 산출근거 공식 자동 생성.
- **디젤 매연 (광투과식 %)**: 차량 연식별 법정 기준 및 3회 측정 평균 소수점 버림 규칙 수록.
- **가솔린 배기가스 (CO, HC)**: 연식 및 유종(가솔린/LPG)별 기준표.
- **최소회전반경, 사이드슬립, 전조등 광도, 경음기 음량** 기준 및 조치요령 정리.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript (ES6 Modules)
- **APIs**: Screen Wake Lock API, Web Storage API (LocalStorage)
- **Server**: Zero-Dependency Node.js HTTP Server (`server.js`)
- **Hosting**: Vercel Static Hosting Ready (`vercel.json`)
