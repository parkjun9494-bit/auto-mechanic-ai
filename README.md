# 🚗 AutoMechanic AI (오토메카닉 AI)

> **"소음, 떨림, 계기판 경고등부터 정비소 예상 견적까지 — 똑똑한 내 차 자가진단 & 정비 파트너"**

AutoMechanic AI는 운전자가 겪는 차량 이상 증상을 AI 문진 및 빅데이터 기반으로 정밀 분석하여, 유력 의심 부품, 위험도, 예상 수리비, 그리고 정비소에서 바가지(과잉정비)를 쓰지 않도록 정비사에게 보여줄 수 있는 **10초 브리핑 카드**를 즉시 발급해 주는 올인원 자동차 정비 플랫폼입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 🩺 AI 스마트 증상 진단기 (Symptom Diagnostics)
- **4단계 인터랙티브 문진**: 이상 감각(소음, 진동, 출력, 냄새, 연기, 누유), 발생 조건(제동 시, 가속 시, 고속 주행 시, 요철 통과 시 등), 사용자 증상 텍스트 입력.
- **위험도 등급 신호등**: 🔴 즉시 견인 / 🟡 빠른 정비소 입고 / 🟢 주기 점검 권장 3단계 분류.
- **예상 고장 부품 분석**: 1순위 및 2순위 의심 부품, 고장 발생 메커니즘 상세 설명.
- **자가 응급 조치 요령**: 권장 행동(DO)과 절대 하지 말아야 할 행동(DON'T) 안내.
- **예상 정비 견적서**: 국산차 vs 수입차 부품대 및 표준 공임 분리 산출.
- **정비사 전달용 10초 브리핑 카드**: 차종, 증상 요약, 점검 요청 사항을 전문 용어로 일목요연하게 정리 (원클릭 클립보드 복사 & 리포트 인쇄 지원).

### 2. 🔊 Web Audio 고장 소음 시뮬레이터 (Noise Simulator)
- 브레이크 패드 마모 쇳소리(고주파 마찰음)
- 허브 베어링 손상(헬리콥터 비행 공명음)
- 겉벨트/팬벨트 슬립음(끼이익)
- 등속조인트 손상(핸들 꺾을 때 딱딱 소음)
- 엔진 노킹음(자갈 굴러가는 까르륵 소리)
운전자가 실제 차에서 나는 소리와 직접 비교 청취 가능.

### 3. ⚠️ 계기판 경고등 마스터 도감 (Warning Lights Guide)
- 🔴 위험(즉시 정차), 🟡 경고(점검 요망), 🟢 정상 표시등 등 60여 종 수록.
- 색상별 필터 및 실시간 키워드 검색.
- 경고등별 원인, 즉시 조치법, 주행 계속 가능 여부, 예상 수리비 상세 모달 지원.

### 4. 📅 소모품 교체 주기 및 D-Day 스마트 계산기 (Maintenance Scheduler)
- 유종별(가솔린, 디젤, 하이브리드, EV) 특화 주기 자동 산출.
- 12대 핵심 소모품(엔진오일, 브레이크 패드/액, 미션오일, 배터리, 점화플러그, DPF, EV 감속기오일 등) 잔여 수명(%) 및 잔여 거리 시각화.
- 교체 임박/초과 알림 및 알짜 정비 팁 제공.

### 5. 💰 정비 표준 견적 & 소비자 보호 가이드 (Cost & Shield)
- 30대 대표 정비 항목 부품대, 표준 공임, 총비용 가이드북.
- 자동차관리법상 소비자 법적 권리 (정비견적서 발급 의무, 60일/3,000km 무상보증, 고품 확인 요령 등).

### 6. 💬 AI 수석 정비사 1:1 상담 (Live AI Chat)
- 차량 이상 증상 및 정비 견적에 대해 자유롭게 질의응답 가능한 대화형 AI 상담.

### 7. 🚘 내 차고 & 진단 기록 관리 (Garage & History)
- 내 차량 정보(차종, 연식, 유종, 주행거리) 등록 및 수정.
- 과거 진단 결과 브라우저 로컬 저장 및 백업(JSON 내보내기) 지원.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript (ES6+ Modules), Lucide Icons
- **Audio Synthesis**: Web Audio API (FM Synthesis & Noise Buffers)
- **Storage**: Browser LocalStorage & JSON Backup Engine
- **Server**: Lightweight Zero-Dependency Node.js HTTP Server (`server.js`)
- **Hosting**: Vercel Static Hosting Ready (`vercel.json`)
